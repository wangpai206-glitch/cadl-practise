# docs 阅读导引

这份导引是教材新增说明，不属于上游原文。此目录保留最初 ZIP 中的 4 份开发文档；浮点版本的第 5 份位于 `../float-current/docs/SYNTHESIS/`。

请先打开 [教程第 28 节 docs 导读](../../开始阅读.html#lesson-28)，再读第 29～35 节硬件交互篇。第 31 节有 ready/valid 握手演示，第 35 节有一次 GEMM 的分步数据旅程。

| 文件 | 主要内容 |
|---|---|
| [CADL 语言手册](SYNTHESIS/cadl-language.md) | 类型、寄存器和内存访问、循环、指令编码、优化属性 |
| [APS 接口](ARCHITECTURE/aps-itfc.md) | CPU 发命令、操作数传入、访问内存、返回结果及平台适配 |
| [DMA 引擎](ARCHITECTURE/dma-engine.md) | 批量搬运、总线请求与响应、存储 bank、布局、对齐和并发 |
| [综合流程](SYNTHESIS/aps-e2e-flow.md) | 编译变换、调度、存储和接口生成、跨周期队列及 RTL |
| [浮点语义与验收](../float-current/docs/SYNTHESIS/hardfloat-bf16-fp32-acceptance.md) | BF16/FP32 运算、舍入、握手、复位、功能验证与物理时序 |

旧文档是概念资料，部分示例不是当前 float 版本的可执行写法：`_burst_read/_burst_write`、带逗号的多个循环绑定、`opt → sv` 任务等应对照实际源码。当前 GEMM 使用 128 字节 DMA 行，不以旧文档里的“通常 64B”或“约 15 周期”作为实验配置和实测结果。

`aps-itfc.md` 的 burst 原子性描述不能直接推导出系统级原子读写保证；先写后读被标为 WAR 的地方也不准确。详细差异和当前案例见第 28 节。

这里只收录选定参考资料，原文链接到的 `deployment.md` 等未全部打包。没有这些文件不意味着你漏读了教程某一节。
